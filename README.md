# ESP8266 MAX7219 NTP Clock 🕒

Простий та точний годинник реального часу на базі мікроконтролера **ESP8266** та світлодіодної матриці **MAX7219 (8x8)**. Синхронізація часу здійснюється автоматично через Wi-Fi за допомогою протоколу **NTP**.

---

## 🚀 Особливості
* **Автоматична синхронізація:** Час завантажується з NTP-серверів при підключенні до мережі.
* **Компактний шрифт 3x3:** Години та хвилини відображаються одночасно на одній матриці 8x8 (години зверху, хвилини знизу).
* **Статичний вивід:** Без анімацій, блимання та перемикання екранів.
* **Економія ресурсів:** Швидка робота через апаратний/програмний SPI та бібліотеку `LedControl`.

---

## 🛠 Компоненти та Залізо
* **Мікроконтролер:** ESP8266 (Wemos D1 mini / NodeMCU)
* **Дисплей:** Світлодіодний модуль MAX7219 (матриця 8x8)
* **З'єднувальні дроти (Dupont)**

---

## 🔌 Схема підключення

| Модуль MAX7219 | ESP8266 (Wemos D1 mini / NodeMCU) | Примітка |
| :--- | :--- | :--- |
| **VCC** | **5V / VIN** | Живлення 5В |
| **GND** | **GND** | Спільна земля |
| **DIN** | **D7 (GPIO13)** | Data In (MOSI) |
| **CS** | **D6 (GPIO12)** | Chip Select |
| **CLK** | **D5 (GPIO14)** | Clock (SCK) |

---

## 📚 Необхідні бібліотеки
Для збірки проєкту в **Arduino IDE** або **PlatformIO** потрібні такі бібліотеки:

1. **LedControl** (by Eberhard Fahle) — керування драйвером MAX7219.
2. **NTPClient** (by Fabrice Weinberg) — отримання часу через мережу.
3. **ESP8266WiFi** (входить до складу ядра ESP8266).
